Mac 电脑版（macOS），不是 iPhone/iPad 应用。

解压后，在 Mac 上打开「安装奶蛙.command」，选择一个可写的安装文件夹。安装器会从 Electron 官方 GitHub 下载该 Mac 处理器对应的运行环境并校验 SHA-256，所以安装时需要联网。运行环境的最低 macOS 要求以下载版本为准。
安装时选择「仅本机使用」或「启用远程控制」。启用后仍使用原来的控制网站和二维码；每台设备有独立身份，可在网页分别选择。

双击奶蛙：所有现有奶蛙大笑，大笑结束后新增一只不同初始形态的奶蛙；新增的一只不参与本轮大笑。右键可停止大笑、恢复为一只、切换九种形态、退出。可拖动奶蛙。
右键不显示远控条目。安装文件夹内的「连接设置.command」可启动或关闭远控、移除设备配对。菜单栏点击奶蛙图标也能打开同一设置。启用时菜单栏标明远程控制及连接状态。

这份包由 Windows 环境准备，已做脚本与协议检查，未在 Mac 实机运行验证。它未使用 Apple 开发者证书签名或公证，首次打开可能需要按 macOS 自身的安全提示确认。安装脚本在本机组装并作本地签名，不修改系统安全设置。
退出奶蛙后，可将安装目录中的 .app、连接设置.command 和 remote-control.ini 移到废纸篓。设备凭据保存在当前用户的应用支持目录中，并由系统钥匙串保护；需要解除远程配对时先用连接设置中的「移除设备配对」。
